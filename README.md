# pinguin
Pinger with VK bot interface without WebHook — port of https://github.com/abakum/tmbPi

## Создание сообщества и получение токена

1. **Создайте сообщество**: [vk.com/groups](https://vk.com/groups) → «Создать сообщество» → выберите любой тип (например «Группа по интересам») → задайте название.
2. **Включите сообщения сообщества**: «Сообщения» → «Сообщения сообщества» — «Включены». Приветствие и виджет сообщений не нужны.
3. **Включите возможности ботов**: «Сообщения» → «Настройки для бота» — включите «Возможности ботов: Включены» и «Разрешать добавлять сообщество в чаты». Кнопка «Начать» не нужна.
4. **Получите ключ доступа** (токен сообщества): откройте сообщество (вы должны быть администратором) → в меню справа **Управление → Дополнительно → Работа с API** → вкладка **Ключи доступа** → **Создать ключ** → выберите права **Управление сообщениями** (`messages`) → **Создать** → подтвердите действие в мобильном приложении ВКонтакте или по СМС. Ключ появится на вкладке «Ключи доступа» — скопируйте его в `run.cmd`. Там же можно создать несколько ключей с разным набором прав или в любой момент отозвать ключ.
5. **Включите Long Poll API**: «Работа с API» → **Long Poll API** — включите «Long Poll API: Включено». Затем там же на вкладке «Типы событий» отметьте все чекбоксы раздела **Сообщения** (Входящее сообщение, Исходящее сообщение, Редактирование сообщения, Действие с сообщением, Разрешение на получение, Запрет на получение, Статус набора текста, Прочитанность сообщений, Действие с реакциями на сообщение) и раздела **Пользователи** (Подписка на сообщество, Выход из сообщества) — бот реагирует и на эти события. Изменения сохраняются автоматически («Изменения сохранены»).
6. **Создайте чат в сообществе**: «Сообщения» → «Чаты сообществ» → «Чаты» → создайте чат, в котором будет работать бот, и укажите его peer ID в `run.cmd` как `2000000001`.

## Usage
```
TOKEN=VK_COMMUNITY_TOKEN pinguin AllowedPeerID1 AllowedPeerID2 AllowedPeerIDx
```
- `TOKEN` — токен сообщества VK (Bots API, long polling)
- аргументы — разрешённые peer ID (положительные для ЛС и чатов)
   - `AllowedPeerID1` — владелец: на его peer ID (`chats[0]`) шлются сообщения об ошибках, а его UserID разрешён в любом чате. Узнать свой ID можно на [id.vk.ru/account/#/personal](https://id.vk.ru/account/#/personal)
  - `AllowedPeerID2`, `AllowedPeerIDx` — остальные разрешённые чаты/пользователи
- состояние пингов не переносится со старого `tmbPing.json` — начинается с чистого файла

## Запуск на Windows

`run.cmd` собирает (`go install`) и запускает бота в отдельном окне:

```cmd
@echo off
rem Run pinguin VK bot on Windows
cd /d %~dp0

set bot=PingBot
set TOKEN=YourCommunityTokenHere
set goBin=%USERPROFILE%\go\bin
set PEER_IDS=123456789 2000000001

go install
start "%bot%" %goBin%\pinguin.exe %PEER_IDS%
```

Укажите в `run.cmd` свой `TOKEN` и список `PEER_IDS` перед запуском.
