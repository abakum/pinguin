# pinguin
Pinger with VK bot interface without WebHook — port of https://github.com/abakum/tmbPi

## Создание сообщества и получение токена

1. **Создайте сообщество**: [vk.com/groups](https://vk.com/groups) → «Создать сообщество» → выберите любой тип (например «Группа по интересам») → задайте название.
2. **Включите сообщения сообщества**: «Сообщения» → «Сообщения сообщества» — «Включены». Приветствие и виджет сообщений не нужны.
3. **Включите возможности ботов**: «Сообщения» → «Настройки для бота» — включите «Возможности ботов: Включены» и «Разрешать добавлять сообщество в чаты». Кнопка «Начать» не нужна.
4. **Получите ключ доступа** (токен сообщества): откройте сообщество (вы должны быть администратором) → в меню справа **Управление → Дополнительно → Работа с API** → вкладка **Ключи доступа** → **Создать ключ** → выберите права **Управление сообщениями** (`messages`) → **Создать** → подтвердите действие в мобильном приложении ВКонтакте или по СМС. Ключ появится на вкладке «Ключи доступа» — скопируйте его в `.env` (переменная `pinguin_token`) или в Windows Credential Manager (запись `pinguin_token`). Там же можно создать несколько ключей с разным набором прав или в любой момент отозвать ключ.
5. **Включите Long Poll API**: «Работа с API» → **Long Poll API** — включите «Long Poll API: Включено». Затем там же на вкладке «Типы событий» отметьте все чекбоксы раздела **Сообщения** (Входящее сообщение, Исходящее сообщение, Редактирование сообщения, Действие с сообщением, Разрешение на получение, Запрет на получение, Статус набора текста, Прочитанность сообщений, Действие с реакциями на сообщение) и раздела **Пользователи** (Подписка на сообщество, Выход из сообщества) — бот реагирует и на эти события. Изменения сохраняются автоматически («Изменения сохранены»).
6. **Создайте чат в сообществе**: «Сообщения» → «Чаты сообщества» → «Чаты» → создайте чат, в котором будет работать бот, и укажите его peer ID в `pinguin_ids` (например `2000000001`).

## Usage
```
pinguin_token=VK_COMMUNITY_TOKEN pinguin_ids="AllowedPeerID1 AllowedPeerID2 AllowedPeerIDx" pinguin
```
- `pinguin_token` — токен сообщества VK (Bots API, long polling)
- `pinguin_ids` — разрешённые peer ID (положительные для ЛС и чатов), через пробел и/или запятую
   - `AllowedPeerID1` — владелец: на его peer ID (`chats[0]`) шлются сообщения об ошибках, а его UserID разрешён в любом чате. Узнать свой ID можно на [id.vk.ru/account/#/personal](https://id.vk.ru/account/#/personal)
  - `AllowedPeerID2`, `AllowedPeerIDx` — остальные разрешённые чаты/пользователи
- порядок источников значений: переменные среды → `.env` в рабочей директории → Windows Credential Manager (только Windows, записи `pinguin_token` и `pinguin_ids`)
- состояние пингов не переносится со старого `tmbPing.json` — начинается с чистого файла

## Настройки

Пример `.env` лежит в корне репо:
```
pinguin_token=VK_COMMUNITY_TOKEN
pinguin_ids=123456789 2000000001
```
Замените заглушки на свои значения. Не коммитьте `.env` с реальным токеном.

На Windows значения можно положить в Credential Manager (обычные учётные данные) вместо `.env`:
- GUI: Панель управления → Учётные записи пользователей → Диспетчер учётных данных → «Общие учётные данные» → «Добавить общие учётные данные»: адрес/имя сети — `pinguin_token`, пароль — значение токена; аналогично для `pinguin_ids`
- CLI: пример в `windows_credential.bat` в корне репо:
```bat
cmdkey /generic:pinguin_token /user:pinguin /pass:VK_COMMUNITY_TOKEN
cmdkey /generic:pinguin_ids   /user:pinguin /pass:"123456789 2000000001"
```
`/user` обязателен для `cmdkey`, но при чтении не используется — бот ищет записи по имени из `/generic`.
