# Протокол чужих нажатий кнопок на статусных реплях + рабочие часы

## Контекст

Было: в `onMessageEvent` кнопки на чужих статусных реплаяx запрещены (`my` по маркеру `@id<N>`, `my == false` → «Батюшка не благословляет Вас»), воркер жил по 8-часовому дедлайну.

Пример реплая: `✅ 127.0.0.1 КА @id229928246` (имена — инициалами).

## Итоговое решение (подтверждено пользователем, отражает все правки)

- **🔁 на чужом** — выполняется как свой, без протокола; снackbar нейтральный на любом реплае (в т.ч. без маркера).
- **⏸️ на чужом** — нажатый реплай **удаляется и заменяется новым протокольным реплаем** (не правкой на месте: `messages.edit` роняет reply-заголовок, `keep_forward_attachments` не спасает). Новый реплай — с клавиатурой kbIP, ответом на исходный запрос, текст: `<статусВмоментТапа>⏸️ <ip> <инициалыТапнувшего> @id<тапнувший> @id<автор>` (пример: `✅⏸️ 127.0.0.1 ИП @id111 @id229928246`).
- **❌ на чужом** (отписать хост) — протокольный реплай **без клавиатуры** (`sendKeyboard(..., nil)` — без явного nil sendKeyboard ставит kbIP): `<статусВмоментТапа> <ip> ❌<инициалы> @id<тапнувший> @id<автор>`. Затем тапнувший подписывается, и каждый старый подписчик отписывается командой `❎` (его реплаи удаляются). Итог: единственный подписчик — тапнувший, его реплай с клавиатурой и маркером `<новыйСтатус> <ip> <инициалы> @id<тапнувший>`.
- **❎ на чужом** (отписать подписчика) — протокольный реплай без клавиатуры с `❎<инициалы>`; нажатый реплай удаляется; тапнувший подписывается, командой `❎` отписывается **автор** (его реплаи удаляются во всех пирах); остальные подписчики живы.
- **Свои нажатия** — молча, как раньше.
- **Рабочие часы**: в 18:00 МСК программно нажимается `…⏸️`, в 08:00 МСК — `…🔁` (единственные правила; никакой «автопаузы по времени суток» при старте нет — воркер стартует с `paused=false`, пауза приходит только реальной командой ⏸️). Дедлайн (8-часовой цикл) удалён полностью.
- Имена — инициалами везде (`userMention`): «Константин Абакумов» → «КА».

## Реализация

### vk.go

- `userMention` — инициалы через новый хелпер `initials()` (первая буква каждого слова, uppercase); кэш хранит полные имена.
- `editMessage` — передаёт `keep_forward_attachments=1` (используется `editPanel`; для ⏸️-протокола правка больше не применяется).
- `sendKeyboard(..., nil)` — явный nil = без клавиатуры; без аргумента ставит kbIP по умолчанию.

### global.go

- `reAuthor = (?:@id(\d+)|\[id(\d+)\|[^\]]*\])\s*$` — маркер в двух формах: отправленный `@id<N>` и возвращаемый API упоминанием `[id<N>|…]` (VK конвертирует @id при отправке; в UI скобок не видно, в тексте из API они есть).
- `customer.Deadline` — поле оставлено для чтения старых pinguin.json, не пишется и не читается.

### main.go — `onMessageEvent` + `foreignButton`

- `authorID`: маркер `reAuthor` (обе формы, m[1]/m[2]); иначе фолбэк `tm.ReplyMessage.FromID` **только при > 0** (родитель-бот с отрицательным id не автор — CLI-запросы шлёт сам бот). `my := obj.PeerID == obj.UserID || obj.UserID == authorID`.
- `allowed := my || Data == "🔁" || authorID > 0 && (⏸️/❌/❎)` — снackbar.
- `foreignButton` (main.go): guard `authorID <= 0 || ip == "" || !ips.read(ip)` → ignore с логом. `reqCmid` = `tm.ReplyMessage.ConversationMessageID`, fallback `msgID(tm)`.
  - ⏸️: отправить новый протокольный реплай с kbIP → удалить нажатый (`tm.ID`) → `ips.write(ip, customer{Cmd: "⏸️", PeerID, UserID: authorID, ReplyID: <новый>})`. При ошибке отправки — обычная пауза без протокола.
  - ❌/❎: протокол `sendKeyboard(..., nil)`; при `reqCmid > 0` подписать тапнувшего (`customer{PeerID, UserID: obj.UserID, MsgID: reqCmid}`, `MsgID != 0` обязателен), затем ❎-команды: для ❌ — всем из снапшота `hosts.list()[ip].Cus` (fallback — автору), для ❎ — автору.
- Лог нажатия расширен: `MessageEvent <Data> … author <N> <полный текст реплая>`.
- `workHours()`/`msk`: фиксированная зона UTC+3 (`time.FixedZone`, без tzdata); планировщик спит до границы 08:00/18:00 МСК и жмёт `ips.update(customer{Cmd: "⏸️"|"🔁"})` — тот же путь, что кнопки `…⏸️`/`…🔁` на панели; goroutine рядом с главным циклом, выход по `mainCtx.Done()`. `afterHours()` **удалена**.

### worker.go

- `deadline` удалён; `paused bool` = false на старте; import `time` убран.
- Пинг при `!paused`; в паузе — суффикс ⏸️ к статусу; на первом цикле (`status == ""`) даже в паузе один сеяющий пинг, чтобы рестарт в паузе не давал голый `⏸️ ip` без ❗/✅.
- Ветка `⏸️`: `paused = true`; при `cust.ReplyID != 0` (чужая пауза) — подмена `cus[i].ReplyID = cust.ReplyID` для `cu.UserID == cust.UserID` (автору) и skip пересоздания этого реплая в цикле рассылки (`cust.Cmd == "⏸️" && cust.ReplyID != 0 && cu.ReplyID == cust.ReplyID`).
- Ветка `🔁`: `paused = false`, перепинг.
- save/load: без `Deadline`; load-записи распознаются по `Cmd == ip`.
- Прочие ветки (cmdVerify, ❎-фильтр, …❌-условия) — без изменений.

## Правки по итогам эксплуатации (хронология)

1. Чужой 🔁 получал «Батюшку» на реплае без маркера → 🔁 разрешён безусловно.
2. Отказы «на своём»/«на чужом» на маркированных реплаях → лог с `author` и текстом показал: VK отдаёт маркер формой `[id<N>|@id<N>]` → `reAuthor` расширен на две формы; фолбэк по родителю ограничен `FromID > 0` (родитель — сам бот, `-241064685`).
3. Чистка «старых дублей» в `cleanupOrphans` (реплаи без маркера при мониторимом IP) оказалась слишком агрессивной и вычистила живые реплаи → **откатена**; старые реплаи обслуживаются фолбэком по родителю.
4. Протокольный реплой ❌/❎ приходил с кнопками → `sendKeyboard(..., nil)`.
5. ⏸️-протокол правкой на месте превращал реплай в обычное сообщение (edit роняет forward, `keep_forward_attachments=1` не помог) → переделано на «удалить и реплэить» с adoption нового ReplyID в воркере.
6. Голый `⏸️ ip` после рестарта в паузе → сеяющий пинг на первом цикле.
7. `afterHours()`-инициализация паузы при старте признана лишним правилом (запрос после 18:00 отвечал паузой) → удалена; пауза только от реальной команды ⏸️. Следствие осознано: рестарт ночью возобновляет пинговку до ближайших 18:00.

## Сценарии проверки

1. Чужой 🔁 → перепинг, реплай обновляется, ничего лишнего; на реплае без маркера — тоже работает, снackbar нейтральный.
2. Чужой ⏸️ → нажатый реплай удалён, появился новый реплай-ответ `✅⏸️ 127.0.0.1 ИП @id111 @id229928246` с кнопками, воркер в паузе; автор по маркеру в конце — прежний.
3. Чужой ❌ → протокольный реплай **без кнопок**, реплаи старых подписчиков удалены, новый реплай тапнувшего с кнопками.
4. Чужой ❎ → протокол без кнопок с `❎`, реплаи автора удалены, тапнувший подписан.
5. Свои 🔁/⏸️/❌/❎ — молча, как раньше.
6. 18:00 МСК → всем воркерам программное `…⏸️` (реплаи `❗⏸️ …`); 08:00 МСК → `…🔁`. Рестарт в паузе → реплай `❗⏸️ …` (не голый `⏸️`).
7. `gofmt -l .` пусто, `go vet ./...`, `go mod tidy`, `go build ./...`, `make win`.

## Риски

- Подписка-перехват требует `reqCmid > 0`; при нуле — отписка без перехвата (лог).
- `hosts`-снапшот для ❌ может отставать — fallback отписки автора.
- Дубликат подписки тапнувшего — как при повторном текстовом запросе.
- `userMention` пустое имя — строка валидна за счёт `@id<N>`.
