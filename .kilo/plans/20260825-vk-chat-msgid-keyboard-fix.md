# Исправление: молчание бота в чате сообщества VK + лимит клавиатуры

## Проблема 1 — бот игнорирует сообщения в чате сообщества (peer 2000000001)

В чатах сообществ VK `message_new` приходит с `tm.ID == 0`; реальный
идентификатор лежит в `tm.ConversationMessageID`. `bhAnyWithMatch`
(main.go:194, 200, 206) передаёт `tm.ID` как `MsgID`, поэтому запрос
попадает в ветку «update» (worker.go:41) вместо «subscribe» (worker.go:66) —
список подписчиков пуст, статусное сообщение не отправляется никогда.

Примечание: `MsgID` в итоге используется как `reply_to`, а API VK там ожидает
именно *conversation message id*, значит `ConversationMessageID` — корректное
значение везде.

### Исправление

В `main.go` (`bhAnyWithMatch` и остальные обработчики, использующие `tm.ID`
для ответа: main.go:206, 308, 324, 341):

- Добавить помощника:
  ```go
  func msgID(tm *object.MessagesMessage) int {
      if tm.ConversationMessageID > 0 {
          return tm.ConversationMessageID
      }
      return tm.ID
  }
  ```
- Заменить `MsgID: tm.ID` → `MsgID: msgID(tm)` и
  `sendKeyboard(tm.PeerID, tm.ID, ...)` → `sendKeyboard(tm.PeerID, msgID(tm), ...)`
  во всех обработчиках сообщений.

## Проблема 2 — `Keyboard format is invalid: keyboard contains too much buttons`

Inline-клавиатура в vk.go:21-39 содержит 12 кнопок; лимит VK — 10. После
исправления проблемы 1 каждое `messages.send` будет падать с этой ошибкой.

### Исправление (решение пользователя: убрать 🔂, …🔂, ❎; остальное сохранить)

В vk.go:21-39 убрать кнопки `🔂` (ряд 1), `…🔂` (ряд 2), `❎` (ряд 1):

- Ряд 1: 🔁 ⏸️ ❌ (3)
- Ряд 2: …🔁 …⏸️ …❌ (3)
- Ряд 3: …✅❌ …❗❌ …⏸️❌ (3)

Итого 9 кнопок — в пределах лимита; все условные групповые стопы сохранены.

Изменения в коде:

- vk.go:23-28 — убрать `.AddCallbackButton("🔂", ...)` и `.AddCallbackButton("❎", ...)`
- vk.go:29-33 — убрать `.AddCallbackButton("…🔂", ...)`
- main.go:240-246 (`onMessageEvent`, ветка `Data == "❎"`) — убрать обработку ❎,
  так как кнопки больше нет (удаление сообщения остаётся доступно через
  ответ «−» → `bhReplyMessageIsMinus`).
- worker.go:47-48 (`case "🔂"`) — убрать кейс целиком: кнопки больше нет,
  разовый замер достигается естественным истечением дедлайна.
- worker.go:50-52 — обработку условных стопов не трогать по той же причине.
