# Ответ на `/команду`: два пульта в ЛС своим, всем остальным — текст без клавиатуры

## Контекст

- `bhAnyCommand` (main.go:300-323) на любую `/команду` шлёт одно сообщение
  «Ожидался список IP адресов…» с `kbGroup` (два ряда …-кнопок) в reply.
- `sendKeyboard` (vk.go) — variadic `kbs ...*object.MessagesKeyboard`:
  без аргументов → `kbIP`; явный `nil` сейчас тоже даёт `kbIP`,
  «вообще без клавиатуры» отправить нельзя.
- `allowed(FromID, PeerID)` (main.go) истинен, если `FromID` ИЛИ `PeerID`
  в `chats` (PEER_IDS из аргументов запуска) — в разрешённом чате 200000000X
  проходит любой участник. Для нового правила это НЕ подходит.

## Решения (финальная спецификация пользователя)

1. `/restart`, `/stop` для владельца (первый PEER_ID, проверка
   `chats[:1].allowed(tm.FromID)`) — без изменений, работают и в чатах.
2. **Пульты** — только в личке с ботом от пользователя из PEER_IDS:
   условие `tm.PeerID == tm.FromID && chats.allowed(tm.FromID)`
   (PeerID == FromID — признак ЛС; в групповом чате PeerID = 2000000000+X).
3. **Все остальные** — включая любые групповые чаты 200000000X (даже
   разрешённые) и посторонние ЛС — получают ровно одно сообщение:
   «Ожидался список IP адресов…\n/127.0.0.1 127.0.0.2 127.0.0.254»
   **без** `ups` («Батюшка не благословляет…») и **без параметра `keyboard`**.
4. Вид пультов (reply на `msgID(tm)`), текст = подписи кнопок:
   - №1: текст `…🔁 …⏸️ …❌`, кнопки `…🔁` `…⏸️` `…❌`;
   - №2: текст `…✅❌  …❗❌  …⏸️❌`, кнопки `…✅❌` `…❗❌` `…⏸️❌`.
5. Прочие вызовы `sendKeyboard` (worker.go:90; main.go — news в
   `bhAnyWithMatch`, `bhLeftChat`, `bhNewMember`) и их гейтинг
   `allowed(FromID, PeerID)` не меняются: по умолчанию `kbIP`
   (ряд 🔁 ⏸️ ❌ ❎); `ups`/`notAllowed` там остаются.

## Изменения

1. **vk.go — клавиатуры**: двухрядную `kbGroup` заменить на две однорядные:
   - `kbGroup1` — ряд `…🔁` `…⏸️` `…❌`;
   - `kbGroup2` — ряд `…✅❌` `…❗❌` `…⏸️❌`.
   Неиспользуемые `kb` (полная) и старую `kbGroup` удалить (перед удалением
   убедиться grep'ом, что ссылок нет).
2. **vk.go — `sendKeyboard`**: явный `nil` в `kbs[0]` → не устанавливать ключ
   `"keyboard"` в `api.Params` (VK принимает messages.send без keyboard);
   без аргументов — по-прежнему `kbIP`. Регресса нет: `nil` никто не передаёт.
3. **main.go — `bhAnyCommand`** (~main.go:313-318), вместо `allowed(...)`:
   ```go
   if tm.PeerID == tm.FromID && chats.allowed(tm.FromID) {
       // ЛС с пользователем из PEER_IDS — два пульта
       _, err := sendKeyboard(tm.PeerID, msgID(tm), "…🔁 …⏸️ …❌", kbGroup1)
       // let.Println(err)
       _, err = sendKeyboard(tm.PeerID, msgID(tm), "…✅❌  …❗❌  …⏸️❌", kbGroup2)
       // let.Println(err)
   } else {
       // групповые чаты 200000000X и посторонние — одно сообщение без кнопок
       text := dic.add(ul,
           "en:List of IP addresses expected\n",
           "ru:Ожидался список IP адресов\n",
       ) + "/127.0.0.1 127.0.0.2 127.0.0.254" // без ups
       _, err := sendKeyboard(tm.PeerID, msgID(tm), text, nil)
       // let.Println(err)
   }
   ```
   Вызов `allowed(...)` из `bhAnyCommand` удаляется вместе с `ups`.

## Проверка

1. `go build ./... && go vet ./...`, затем `make win`.
2. Вручную:
   - `/foo` в ЛС от пользователя из PEER_IDS → ровно два reply-сообщения
     с рядами `…🔁 …⏸️ …❌` и `…✅❌  …❗❌  …⏸️❌`, никаких других сообщений;
     оба годятся для закрепления, кнопки работают (групповые команды);
   - `/foo` в чате 2000000001 (владельцем и кем угодно) → ровно одно
     «Ожидался список IP адресов…\n/127.0.0.1 127.0.0.2 127.0.0.254»,
     без кнопок и без «Батюшка не благословляет…»;
   - `/foo` в посторонней ЛС → то же одно сообщение без кнопок;
   - статусные replies по-прежнему с рядом 🔁 ⏸️ ❌ ❎ (kbIP);
   - `/restart`, `/stop` владельца работают как раньше (в т.ч. из чата).
