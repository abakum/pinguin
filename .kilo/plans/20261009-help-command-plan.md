# Справка на «/», сетки запуска, удаление «-»

## Контекст

Ветка «group chats and strangers» в `bhAnyCommand` (main.go:704-713) отвечает на любую «/…» команду от не-владельца коротким текстом «Ожидался список IP адресов…» + пример. Владельцы и разрешённые в ЛС получают панель — их трогаем.

Решения (подтверждены пользователем):

- Полная справка вместо текущего короткого текста.
- Показывается на любую команду, начинающуюся с «/» (как сейчас работает ветка).
- Новый параметр запуска pinguin: список сеток `a.b.c.d/mask` через пробел.
- Смешанные IP в запросе: попадающие в сетки — подписка; непопавшие — отдельный ответ со списком отклонённых IP + справка.
- Разграничение режимов: если все аргументы — валидные CIDR, это сетки pinguin-сервиса; иначе cliSend как сейчас.

## Справка (bhAnyCommand)

Один файл: `main.go`, ветка «group chats and strangers - plain text without keyboard» в `bhAnyCommand`.

Заменить текст на развёрнутую двуязычную справку через `dic.add(ul, "en:...", "ru:...")`, сохраняя текущий стиль (ключи `en:`/`ru:` с `\n` внутри). Строка «Пингую хосты…» — в конце хелпа, только когда сетки заданы: dic хранит только статичную часть, динамический хвост дописывается кодом и не попадает в переводы.

```
ru:
Отправьте описание и IP-адрес хоста (например: Локалхост 127.0.0.1) — подпишу вас на статус ✅/❗.
Кнопки под ответом:
🔁 — возобновить проверки (проверки идут раз в минуту, отчёт — только при смене статуса ✅/❗)
⏸️ — остановить проверки хоста и отчёты; пауза для всех подписчиков
❌ — удалить: хост убирается из отслеживания для всех, ответы удаляются. Не-автору: подписка переходит к вам, прежний автор отписывается
❎ — закрыть: ваш ответ скрывается и вы отписываетесь от хоста во всех чатах, для остальных хост остаётся. Не-автору: как у ❌ — подписка переходит к вам
В 8:00 по Москве все хосты снимаются с ⏸️, в 18:00 ставятся.
Пингую хосты из сетей 10.5.0.0/16, 10.6.0.0/16.   ← только при заданных сетках, иначе строка опускается
```

```
en:
Send a host description and its IP address (e.g. Localhost 127.0.0.1) to subscribe to ✅/❗ status.
Buttons under the reply:
🔁 — resume checks (checks run every minute, a report only on ✅/❗ change)
⏸️ — stop host checks and reports; the pause applies to all subscribers
❌ — delete: the host is removed from monitoring for everyone, replies are deleted. Non-author: the subscription moves to you, the previous author is unsubscribed
❎ — close: your reply is hidden and you are unsubscribed from the host in all chats, the host stays for others. Non-author: like ❌ — the subscription moves to you
At 08:00 Moscow time all hosts are unpaused, at 18:00 paused.
I ping hosts from the nets 10.5.0.0/16, 10.6.0.0/16.   ← only with nets configured, otherwise omitted
```

Последняя строка собирается кодом и добавляется только при заданных сетках: `"\n" + dic.add(ul, "en:I ping hosts from the nets ", "ru:Пингую хосты из сетей ") + strings.Join(cidr, ", ") + "."`; без сеток справка заканчивается строкой про 8:00/18:00.

Тексты выверены по worker.go (paused — глобальный флаг воркера, ❎ отписывает по UserID во всех пирах) и main.go:569-640 (foreignButton: перехват подписки). Клавиатура остаётся `nil` (как сейчас).

## Сетки запуска

Запуск: `pinguin 10.5.0.0/16 10.6.0.0/16 …` — список CIDR через пробел, без сеток — текущее поведение (любой IP).

1. Парсинг аргументов в main() до ветки cliSend: если все `os.Args[1:]` — валидные CIDR (`net.ParseCIDR`), сохранить `[]*net.IPNet` в глобальную переменную (global.go) и продолжить как сервис; если аргументы есть, но не все CIDR — существующий путь cliSend без изменений. Невалидный CIDR среди смешанных аргументов уйдёт в cliSend и завершится его usage-ошибкой — это допустимо.
2. Фильтрация подписок в `bhAnyWithMatch` (main.go:448-455): уникальные IP из сообщения разделить на `inside`/`outside` относительно сеток (сеток нет — все `inside`, текущее поведение). `inside` → `ips.write(...)` как сейчас. Если есть `outside` — отправить `sendKeyboard(tm.PeerID, msgID(tm), "IP вне сетей: 1.2.3.4, 5.6.7.8\n"+справка, nil)` (та же двуязычная схема через dic.add: «en:IP outside the nets: …», «ru:IP вне сетей: …» + текст справки целиком).
3. Тот же фильтр в pingit-пути `l.MessageReply` (main.go:260-276): эхо-запрос и подписка только для IP из сеток, посторонние молча пропускаются (CLI, справку не показываем).
4. `catchUp` идёт через onMessageNew → фильтруется автоматически.

## Удаление «-» ответа

Ответ «-» позволяет любому пользователю удалить любое сообщение бота, включая строки протокола от foreignButton — лазейка для скрытия протокола. Убираем полностью:

- main.go:336-338 — убрать ветку `if tm.ReplyMessage != nil && tm.Text == "-"` в `onMessageNew`.
- main.go:643-662 — удалить `bhReplyMessageIsMinus` целиком.
- Других ссылок нет (проверено поиском); catchUp тоже пойдёт через onMessageNew без этой ветки.

## Отчёт (2026-10-09)

Реализовано полностью, изменения в `global.go` (+22) и `main.go` (+92/−40):

- **Справка на «/»**: `helpText()` (main.go) — двуязычная справка про подписку и кнопки 🔁/⏸️/❌/❎, расписание 8:00/18:00 по Москве; строка «Пингую хосты из сетей …» дописывается кодом только при заданных сетках (`n.String()`, запятая-разделитель), dic хранит лишь статичные строки. `bhAnyCommand` для групп и незнакомцев шлёт `helpText()` с `nil`-клавиатурой вместо «Ожидался список IP адресов».
- **Сетки запуска**: `parseNets()` (main.go) — все аргументы валидные CIDR (`net.ParseCIDR`) → сервис с глобальной `nets []*net.IPNet` (global.go) и хелпером `inNets(ip)` (нет сеток — разрешён любой IP); иначе прежний ветка cliSend без изменений. `bhAnyWithMatch` делит уникальные IP на inside/outside: inside → `ips.write` как раньше, outside → ответ «IP вне сетей: 1.2.3.4, …» + справка. pingit-путь `MessageReply` фильтрует по `inNets` молча (без эха и без справки); `catchUp` фильтруется автоматически через `onMessageNew`.
- **«-» удалён**: ветка в `onMessageNew` и `bhReplyMessageIsMinus` целиком, других ссылок не было.
- Комментарий main() про one-shot send поправлен на pingit.

Проверки: `gofmt -l .` — пусто; `go vet ./...` — чисто; `go mod tidy` — без изменений; `go build ./...` — ок; `make win` — собраны `pinguin.exe` и `pingit.exe` (v0.0.4, 0490168).
